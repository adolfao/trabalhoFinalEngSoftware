# Resolução Grade universitária

## Infos Gerais

Adolfo, Isabelle e ...

Um sistema que define a grade de um curso de uma universidade, ele define o horário das matérias relacionado com o dos professores.  

Resolve o problema do coordenador de demorar muito ou não conseguir montar os horários da matéria da grade com o horário dos professores.
